# frontend_emc — демо-стенд «проприетарной ЭМК» (система вендора)

Утилитарная типовая российская поликлиническая ЭМК (жанр ЕМИАС/qMS): плотные
таблицы, серо-синяя палитра, Tahoma, вкладки, статусы приёма. Ноль градиентов
и ноль «ИИ-дашбордов» — выглядит как система, в которой врач работает 8 часов.

**Принципиально:** это отдельная система вендора «ООО «МедИнформСистемы»»:
свой сервер (`backend_emc/server.py`, порт 8100, свой API `/api/emc/*`,
«своя» БД пациентов `backend_emc/data/`), свой вход (локальная сессия ЭМК,
не JWT COMPASS). Здесь НЕТ ни одной строки COMPASS.

**Сайдбар COMPASS работает ПОВЕРХ этой системы** (см. `frontend_compass/`):
агент считывает данные с экрана карты (agent.js, инжект букмарклетом —
мини-версия браузерного расширения), ЭМК не модифицируется. Это и есть
архитектура реального внедрения: виджет поверх проприетарной МИС УЗ.

Демо-вход: любой врач из списка (пароль не требуется — демо-стенд вендора).
Все пациенты синтетические/обезличенные (152-ФЗ).
