CDSS для ведения пациентов с тревожно-депрессивной симптоматикой (препарат Авиандр®/маритупирдин). Три контура поверх реальной поликлиники: ЭМК вендора → сайдбар-ассистент врача → PWA пациента.

Сценарий проверки за 3 минуты

  • Врач: установить закладку (п.1) → открыть ЭМК (п.3) → журнал приёма → карта пациента → закладка «COMPASS ▸» → светофор, what-if CYP2D6, кластер-карта, факты действия, НЯ + извещение 1071, HAM-A-14, ответ пациенту.
  • Пациент: QR от врача (п.2) → чек-ин → опросник недели → «Связь с врачом» → сообщение приходит врачу.
  • Алертинг: в PWA пройти каскад SAFETY с позитивным ответом — врачу мгновенно уходит критический алерт (доставка измеряется в мс, метрика видна в дашборде).
