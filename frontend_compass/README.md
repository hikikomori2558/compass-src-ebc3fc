# frontend_compass — продукт COMPASS: сайдбар врача поверх чужой ЭМК

Три файла, ноль правок ЭМК:

| Файл | Роль |
|---|---|
| `install.html` (+ `compass.css`) | Хаб установки: вход врача (живой JWT), кнопка-букмарклет агента для панели закладок, ссылка на ЭМК |
| `agent.js` | Экранный агент: инжектится в ЭМК букмарклетом (мини-версия браузерного расширения), считывает ВИДИМЫЕ данные карты (ФИО, диагноз, жалобы, заключение, лаборатория, шкалы), подсвечивает считанное и открывает поверх ЭМК iframe-сайдбар, передавая экранный документ postMessage |
| `sidebar.html` / `sidebar.js` | Панель врача (свой origin, свой JWT): светофор → подтверждения → находки ОХЛП → PK RK45 168ч → маршрутизация → XAI SHAP (ГОСТ Р 59921) → CBR-когорты РКИ → паспорт провенанса → ф. 057/у-04 → QR-привязка пациента → WS-критические алерты |

**Цепочка (реальные условия):** ЭМК (вендор, 8100, не модифицирована) →
закладка «COMPASS ▸» → агент читает экран → postMessage → сайдбар сам зовёт
`/api/v1/compass-bio/ehr/analyze-and-route` (Bearer врача) → разбор на панели.
ЭМК и COMPASS — разные origin'ы и процессы; клиника идёт только из панели
в наш API по TLS-токену.

Дизайн панели — намеренно инженерный (белый/синий #0f62fe), НЕ похожий на
ЭМК и НЕ «ИИ-дашборд»: врач видит границу систем.
