Рабочее место врача: 3 шага

1
Войдите как врач COMPASS (ЖИВОЙ API, JWT):
Сессия не найдена — войдите.
2
Перетащите кнопку на панель закладок браузера — это агент COMPASS (мини-версия расширения; в проде ставится как extension/iframe-виджет):
COMPASS ▸ ← зажмите и перетащите на панель закладок
3
Откройте ЭМК, войдите, откройте карту пациента и нажмите закладку «COMPASS ▸»: агент считает данные с экрана карты (ЭМК не модифицируется) и поверх неё выедет сайдбар с разбором.
Открыть ЭМК «АИС Поликлиника» → демо-вход в ЭМК: любой врач из списка, пароль не требуется

Архитектура = реальные условия внедрения: ЭМК — отдельная проприетарная система (отдельный процесс и порт, свой API, ноль кода COMPASS внутри). Сайдбар врача — внешний слой, читающий экран и говорящий с API COMPASS. Все пациенты синтетические (152-ФЗ).
