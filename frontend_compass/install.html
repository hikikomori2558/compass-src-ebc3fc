2
Установите агент: перетащите синюю кнопку на панель закладок браузера. Не видите панель закладок? Нажмите Ctrl+Shift+B (Windows) или Cmd+Shift+B (Mac).
COMPASS ▸ ← зажмите мышью и перетащите наверх, на панель закладок
Агент — это мини-версия браузерного расширения: он читает данные с экрана карты пациента и открывает эту панель поверх ЭМК. Файлы ЭМК не изменяются.
3
Работайте в ЭМК: войдите любым врачом, откройте «Журнал приёма» → карта пациента → нажмите закладку «COMPASS ▸». Справа поверх ЭМК появится панель с разбором.
Открыть ЭМК «АИС Поликлиника» → Посмотреть панель отдельно

Если ничего не происходит

Нажал закладку — ничего не случилось Агент работает только на открытой карте пациента (не на журнале). Откройте пациента кнопкой «Открыть карту» и нажмите закладку ещё раз — внизу экрана появится подсказка о состоянии.
Панель открылась, но пишет «Ожидание данных» Панель получает данные только от агента в ЭМК. Убедитесь, что нажали закладку именно на странице карты пациента ЭМК, а сессия врача введена (шаг 1).
Хочу увидеть панель без ЭМК «Посмотреть панель отдельно» → кнопка «Проверить панель на демо-пациенте» — панель прогонит демо-экран через живой API.

Архитектура = реальные условия внедрения: ЭМК — отдельная проприетарная система (свой процесс и порт, свой API, ноль кода COMPASS). Сайдбар — внешний слой: агент читает экран, панель говорит с API COMPASS по JWT. Все пациенты синтетические (152-ФЗ).

Решение принимает врач. Система предупреждает и оформляет.
