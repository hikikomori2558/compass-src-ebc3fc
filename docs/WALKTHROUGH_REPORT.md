## Найдено и починено в ходе прогонов

2. GRANT sequence patient_cluster_profiles (schema.sql давал грант до создания таблицы);
3. **PG16 + FORCE RLS отвергает INSERT … ON CONFLICT DO UPDATE** (проверяет UPDATE-политику даже
   на пустой таблице) → везде UPDATE→INSERT; AUTH_SERVICE добавлен в pcp_select; PATIENT — в
   UPDATE-политику patient_engagement;
4. OOD у всех True → референсные облака в единичном кубе; заменены на клинические центроиды
   кластеров в осях z24 (сигма therapy_day = 40 — курс живёт 1–200 дней); MahD 1260 → 3.6–7.9;
5. проекция точек слипалась → смещение от центроида по ΔGAD-7 (x) и дню терапии (y);
6. import json в bio.py (cluster-map падал 500);
7. patient_diary_entries отсутствовала на живой БД (старый сид) — создана с RLS;
8. intake_time: asyncpg требует datetime.time (strptime), и `datetime.time` перекрыт классом;
9. НЯ в таймлайне: я патчил /insights, а фронт читает /timeline — добавлены adverse_events;
10. total_score numeric → Decimal → строка в JSON: нормализация int в /timeline;
11. NameError diary_symptoms (подъём определения при патче);
12. battle-тест: HADS-A/D ожидания по интерливу, поиск своего пациента, same-day анти-фарминг.
