# UX/UI-дизайн COMPASS — принципы, сценарии, правило трёх кликов

Дата: 24.10.2026. Статус: действующий дизайн-документ для PWA пациента и
сайдбара врача. Всё, что делаем в интерфейсах дальше, сверяем с этим файлом.

## 1. Два пользователя — два характера продукта

| | PWA пациента | Сайдбар врача |
|---|---|---|
| Контекст | телефон, дома, вечером, тревога | рабочий стол ЭМК, 8-часовой поток приёмов |
| Задача | «мне легко рассказать, как я на самом деле» | «быстро увидеть суть, не выходя из ЭМК» |
| Тон | тёплый, поддерживающий, без клиники и жargon | точный, спокойный, доказательный |
| Цвет | мягкий бирюзово-тёплый, много воздуха | белый + семантический светофор |
| Запрет | никакой прямой «суицидальной» лексики до каскада; никакой цифровой шкалы «оцените себя 0–21» | никакой «красоты», затеняющей данные |

## 2. Правило трёх кликов (проверено на каждом сценарии)

**Пациент:**
- Привязка: QR-скан → [Привязаться] → готово. *1 клик.*
- Ежедневный чек-ин: открыть → таблетка (1 тап) → настроение (1 тап) → [Отправить]. *3 клика — базовый чек-ин.*
- Полный опросник (раз в 2 недели): GAD-7 — 7 тапов-ответов (по вопросу на экран, тап = автопереход); PHQ-9 — 9 тапов. *Ни одного поля «введите балл».*
- Сообщить о побочке: Побочки → [Что-то беспокоит] → текст → [Отправить]. *3 клика.*
- Увидеть прогресс: Прогресс → график. *1 клик.*

**Врач (сайдбар поверх ЭМК):**
- Разбор пациента: карта в ЭМК → закладка COMPASS (1) → панель сама с разбором. *1 клик.*
- Подтвердить все «нет» пункты: кнопки «Подтверждаю» в списке, каждая — 1 клик.
- Уведомления: колокольчик (1) → список → подтвердить (1). *2 клика.*
- Полный дашборд состояния: [Развернуть] (1) → дашборд; [Свернуть] (1) → обратно в ЭМК. *Куда бы ни ушёл — возврат в 1 клик.*
- Направление 057/у-04: панель → [Сформировать] → [Печать]. *2 клика.*

Правило: **любая частая операция ≤ 3 кликов; из любого состояния выход в ЭМК — 1 клик.**

## 3. Опросники: клинически корректная подача

Запрещено (анти-паттерны первой версии):
- ❌ «Оцените тревогу 0–21» — пациент не инструмент для самоизмерения;
- ❌ явный дропдаун «Желание умереть / Методы / План» без каскада;
- ❌ прямой вопрос «хотите ли вы, чтобы стало легче» — социально желательный ответ.

Правильно:
- ✅ **GAD-7 / PHQ-9 — валидированные русские формулировки**, по одному вопросу
  на экран, ответы тапами («Совсем нет / Несколько дней / Больше половины / Почти каждый день»),
  тап = автопереход вперёд, итог суммирует клиент;
- ✅ **суицидальный риск — каскад C-SSRS**: сначала нейтральный широкий вопрос
  («Бывали ли за последние 2 недели мысли, что жизнь не стоит того, чтобы жить?»),
  и только при положительном ответе — уточняющие шаги. Отрицание = 0 без стигмы;
- ✅ формулировки вводятся как «за последние 2 недели», как в оригинальных шкалах.

## 4. Обратная связь (то, чего не хватало)

После отправки чек-ина — немедленный экран-фидбек (никогда не «тишина»):
- норма: «✓ Врач увидит ваш ответ сегодня. Неделя 3 из 24 — вы на третьем этапе»
  + мягкий инсайт из данных (тренд относительно прошлого чек-ина);
- критично: отдельный тёплый экран поддержки («Спасибо за доверие. Это важно.
  Ваш врач уже получил уведомление…») + телефон кризисной линии. Без пугающей красноты.

## 5. Побочки — честное ожидание, а не вкладка «справка»

Первая неделя терапии = главный экран страхов пациента. Карточка «Чего ожидать»:
- нормально в дни 1–5: сонливость днём, лёгкая тошнота, головокружение (проходят);
- нормально к неделям 2–4: эффект нарастает постепенно, «прорыв» обычно на 2–3 неделе;
- звонить врачу сейчас: сыпь, сильное сердцебиение, резкое ухудшение;
- кнопка [Что-то беспокоит] — свободная жалоба уходит врачу с чек-ином.

## 6. Сайдбар: панель ↔ дашборд ↔ ЭМК

Три состояния, переходы в 1 клик:
1. **Свёрнуто** — ЭМК на весь экран, кнопка-фаб «COMPASS» снизу справа;
2. **Панель** (440px поверх ЭМК) — светофор, подтверждения, PK, XAI, действия;
3. **Дашборд** (fullscreen поверх всего, из панели кнопкой ⤢) — крупное состояние
   пациента, тренд PK, все уведомления списком, SLA-метрики, горячие действия
   (057/у-04, QR). [Свернуть] возвращает в панель, ✕ — сразу в ЭМК.

Уведомления врача: колокольчик со счётчиком в панели и дашборде; клик — список
неподтверждённых, кнопка «Подтвердить реакцию» в строке.

## 7. Визуальный язык (красиво = спокойно)

- Палитра: фон #f7f9fa, карточки #fff, текст #16242f, акцент бирюза #007d79,
  семантика: зелёный #1f8a4c / янтарный #b7791f / красный #c0392b — только по смыслу;
- Скругления 14px (карточки) / 10px (кнопки), тени мягкие двухслойные;
- Типографика: системный SF/Segoe/Roboto, заголовки 700, плотность текста низкая
  (line-height 1.55+), ключевые числа крупные;
- Микроанимации 150–250ms ease: появление карточек, нажатия кнопок (scale .98),
  переходы экранов — без «эффектности», только понятность;
- Тап-цели на телефоне ≥ 52px высотой; основной сценарий — одной рукой.

## 8. v9: редизайн панели врача — «медицинская записка» (25.10.2026, SSOT)

Основание: docs/UI_RESEARCH.md (ресёрч US/Китай/научлит + живые отзывы врачей).
Проблема v8: 19 из 26 секций — технология; врач не видел «что изменилось» одним экраном;
внешне — ИИ-дашборд из плиток.

### 8.1 Информационная архитектура (панель и дашборд — одна IA)
| Вкладка | Содержимое | Правило |
|---|---|---|
| **Пациент** | Герой-вердикт (светофор + решение + «требуется от вас» + «Не согласен») → «Что изменилось с прошлого визита» (Δшкал со стрелками и датами, приёмы 7 дн., НЯ, жалобы словами + график GAD-7 с линиями КР) → Действия (057, QR, 1071, Источники) | Один герой; красным только «требует действия» |
| **Когорта** | Таблица 105: ярлык, кластер, OOD, GAD-7, приёмы, История/QR/Войти | без изменений |
| **Сообщения** | Выбор пациента → тред PWA ↔ врач → ответ | — |
| **Система** | What-if CYP2D6, микросети, Вассерштейн/Махаланобис, PK 168ч, SHAP, CBR, провенанс, SLA, источники | подпись «врачу в приёме не нужен» — жюри видит всё |

Дашборд (⤢) = та же IA шире: герой на 2 колонки, «Что изменилось» запиской,
HAM-A-14, Сообщения, зона СИСТЕМА (PK, кластер-карта, SLA).
Зоны ПРЕДЛОЖИТЬ/ПРОВЕРИТЬ/РЕШИТЬ сохранены как капс-заголовки (условие кейса),
СИСТЕМА добавлена четвёртой.

### 8.2 Визуальный язык «записки» (перекрывает §7 в части дашборда)
- Секции через линейки 1px #e4e7eb, НЕ карточки-плитки; заголовки секций 11px капс #6b7280.
- Вердикт: белая карточка, цвет = левая полоса 4px + заголовок; фон всегда белый.
- Действия — текстовые ссылки со стрелкой (`.act-link`), не кнопки-плитки.
- Ключевые числа 13px bold в строках записки; график GAD-7 — один, с линиями КР.
- Анти-ИИ-чеклист R4 (UI_RESEARCH.md) — обязателен на каждом скриншоте.

### 8.3 Правила данных записки
- Никаких генеративных резюме: только факты из БД с датами (шкалы/приёмы/НЯ/жалобы).
- Хронология: timeline отдаёт newest-first — всегда разворачивать (улучшение ↓ зелёным).
- Каждый факт отвечает «что с этим делать» (урок отзывов врачей R1).
