# Модель угроз COMPASS-HYBRID v2.6 (одна страница, метрика 13)

Контур: приватный сервер команды → врачи (браузер/PWA), пациенты (PWA). Реализация на
18.10.2026; статус каждой меры — «есть» или «план» (честно для жюри).

## Активы
| Актив | Где живёт | Ценность |
|---|---|---|
| ПДн пациентов (ФИО/телефон/СНИЛС) | `patient_pii_vault` (шифрование на прикладном уровне, роль приложения не имеет прав) | критическая (152-ФЗ ст.10) |
| Клинические данные (ЭМК, шкалы, алерты) | таблицы с RLS | критическая (323-ФЗ ст.13) |
| Критические алерты (суицидальные) | outbox → Redis → WS | жизнь пациента |
| Доступы врачей | `users_auth` (argon2id) | высокая |

## Гарантии, которые мы можем показать жюри прямо сейчас
1. Демо-запрос врачом Б под контекстом врача А → 0 строк (скрин лога теста).
2. `SELECT ... FROM patient_pii_vault` под ролью приложения → отказ в правах.
3. Текст ЭМК с ФИО/телефонами → после scrub в БД уходит только `PII_xxxxxxxx`
   (A/B-тест и сверка HMAC с hashlib — benchmarks/test_pii_scrubber.py).
4. Правило изменилось → новая версия в БД с sha256, старая осталась; откат — одна строка.
5. Аноним → любой клинический API = 401; hot-reload шкал = только ADMIN_METHODOLOGIST;
   подтверждение чужого алерта = 404 через RLS (benchmarks/test_auth.py, test_ws_latency.py).
6. `pip-audit -r requirements.lock.txt` (в python:3.11) → 0 известных уязвимостей.

Примечание о средах: функциональные suite (pytest-стиль, TestClient) гоняются на
локальном py3.9-venv (dev-удобство, starlette 0.49); ПРОДУКТ — Docker-образ на
py3.11/starlette 1.8 из requirements.lock.txt. Полный прогон suite внутри образа —
день 9 (chaos-стенд); сегодня контур доступа образа проверен curl-пробами (401/200/403).
