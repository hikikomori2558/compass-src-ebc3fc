## 0-bis. P0-решения по чек-листу кейса (приняты 18.10, менять только осознанно)

Контекст: чемпионат — 40+ команд с тем же кейсом и более грандиозными презентациями.
Выигрываем не размахом, а проверяемостью и двумя фишками: (1) кластерный анализ К1–К5
по коридорам РКИ, (2) синергия детерминированного C-ядра (ноль галлюцинаций в
назначениях) и advisory-микросетей. Позиционирование и факты —
`docs/REFERENCES_INTERNATIONAL.md` (все ссылки проверены по первоисточникам).

1. **Канал пациента — только PWA на своём домене.** Никаких Telegram Mini App: публикация
   ботов — только для юрлиц РФ (нас нет), а мессенджер = третья сторона в канале врача-пациента
   (нарушение Условия 2). iOS push — только у установленного PWA (16.4+): онбординг-экран
   «Добавить на экран “Домой”» обязателен.
2. **Каналы алерта врачу: WebSocket + Web Push + резерв (email/SMS-шлюз, на демо — эмуляция).
   В канале — пустой пинг «откройте систему», ноль клинического текста.** Неподтверждённые
   алерты висят красным баннером при входе. Метрика алертинга — «время до подтверждения
   человеком», НЕ «45 мс». Цепочка эскалации: нет подтверждения N минут → второй канал →
   второй врач.
3. **Правила — данные, не код.** Готово: `backend/rules_engine.py` + `backend/rules/*.json`
   (8 хард-стопов Авиандра с цитатами ОХЛП, tri-state, альтернативы при блокировке).
   C-ядро Михаила остаётся вычислителем (СКФ/Чайлд-Пью/PK) — так метрика 10 закрыта честно:
   новый препарат = новый JSON. Версии + sha256 → таблица `rule_versions`.
4. **Микросети (день 6) — advisory-прототип на синтетике, вне контура рекомендаций**
   (метрика 5: у нас нет данных обучать то, что влияет на назначения). На слайде так и пишем:
   «диспетчер и детектор аномалий телеметрии; не участвует в назначениях».
5. **Hard stop не блокирует.** Красное предупреждение + override врача с обязательной
   причиной → `audit_log`. Система не «успокаивает пациента» сама: цитата ОХЛП +
   «сообщите врачу» + запись в карточку. Никакой автодифференциации по ст. 29 — только
   уведомление врача + кризисные контакты + черновик направления на подтверждение.
6. **Фичи на вырез** (атака жюри без выигрыша): генотипы как основание выбора препарата,
   nocebo-скор, циркадный индекс, rPPG/Баевский на 30 с записи, «Авиандр при QTc>450»,
   24-мерный вектор целиком (показываем кластеры, не сырые оси).
7. **Честные цифры:** в презентацию не идёт ничего незамеренного; Retention/ROI — гипотезы
   с подписанными допущениями. Проверка итоговых таблиц — `compass_checklist.md` п. 5–6.
8. **Продукт** — по `docs/PRODUCT_DESIGN.md`: врачу — делегирование без страха (подтверждение,
   override, источники по клику); пациенту — ежедневная петля 60 секунд с сериями/скорингом
   (Duolingo-механики против дропаута 1–2-й недели) и ощущением заботы врача.
9. **Инфраструктура проверки:** домашний Debian-сервер в Tailscale-кластере
   (`scripts/deploy_debian.sh`) — Linux/x86_64 сборка (ветка -mavx2) проверена 18.10;
   там же с дня 9–10 — нагрузочные тесты и второй узел для отказоустойчивости.
