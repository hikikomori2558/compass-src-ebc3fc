## Негативное тестирование живого API (сервер без БД, режим degraded)

| Проба | Ответ |
|---|---|
| Запрос без токена | **401** + WWW-Authenticate |
| Доступ к admin-эндпоинту под ролью врача | **403** (роль различается честно, для аудита) |
| Битый JSON | **422** (валидация Pydantic) |
| Пустой текст ЭМК | 200, `AMBER_DATA_REQUIRED` — graceful, без «зелёного» на пустоте |
| Отрицательная доза / абсурдные фенотипы | 200, клиппинг в C-ядре, без 500 |
| Текст ЭМК **500 000 символов** | 200, `AMBER_DATA_REQUIRED` за **239 мс** (Bitap-лексер выдерживает) |
| Swagger UI / OpenAPI | 200 |

Живой смоук эндпоинтов (сценарии демо, фенотипы, hot-reload): `scripts/api_smoke.sh` — 7/7.

## Функциональные тесты

`python3 -m tests.run_all`: **12 сьютов зелёных**, 3 (auth/ws/rls) требуют Postgres/Redis
и закрываются на Debian-стенде (`scripts/demo_debian.sh`).

## Известные осознанные ограничения (демо-режим)

- `CORS_ORIGINS=*` и дев-секреты (`dev_jwt_secret_change_me`, `compass_api_demo`) —
  режим стенда чемпионата; в бою: список доменов МИС в `CORS_ORIGINS`,
  ротация секретов через `.env` (см. `docs/THREAT_MODEL.md`).
- Заглушка F0 в голосовом DSP честно помечена в коде; голосовой контур —
  вне клинических решений.
- Минимальная PK-модель не воспроизводит одновременно тройку ОХЛП
  «Cmax M1 ×6.9 / AUC ×2.9 / T1/2 4.7 ч» — воспроизводится всё, кроме Cmax-отношения,
  отклонение задокументировано в `compass_core.c` и `tests/test_pk_calibration.py`.
