# Аудит: функции платформы → где живут в интерфейсах (24.10)

Проверено всё, что есть в ядре/бэкенде. Формат: функция → эндпоинт → где подключена.

## Подключено к врачу (сайдбар/АРМ)

| Функция | Эндпоинт | Интерфейс |
|---|---|---|
| Безопасный tri-state разбор ЭМК (отрицания, давность) | `/compass-bio/ehr/analyze-and-route` | сайдбар: светофор, подтверждения, находки ОХЛП |
| RK45 168ч фармакокинетика + СКФ/Чайлд-Пью | C-ядро в пайплайне | сайдбар: PK-график; дашборд: Cmax/Cmin |
| XAI SHAP по ГОСТ Р 59921 | в analyze-and-route | сайдбар: таблица топ-факторов |
| CBR-когорты РКИ (5 исследований) | в analyze-and-route | сайдбар: карточки когорт |
| Паспорт провенанса (ГРЛС, sha256 КБ) | в analyze-and-route | сайдбар |
| Фенотипы + дифдиагноз + контрольные точки | в analyze-and-route | АРМ врача; в сайдбаре — черезRouting |
| Экстренный алертинг (Условия 5-6) | `/alerts/unconfirmed`, `/alerts/{id}/confirm`, `/ws/alerts/{doctor}` | сайдбар: баннер + колокольчик + дашборд; ЭМК: красная шапка |
| Таймлайн пациента (шкалы/приверженность/алерты, RLS) — фича Миши | `/compass-bio/patient/{hash}/timeline` | дашборд: «История пациента (БД, RLS)» |
| QR-привязка пациента + код связи | `/auth/invite`, `/auth/bind` | сайдбар: QR + «Скопировать ссылку в буфер» |
| SLA-метрики (Метрики №1, №6) | `/telemetry/summary` | сайдбар: футер; дашборд: карточка |
| Реестр шкал/исследований (ГРЛС) | `/compass-bio/scales-and-trials-registry` | АРМ врача |
| Hot-reload шкал (Метрика №10) | `/admin/hot-reload-scale-plugin` | АРМ врача (ADMIN_METHODOLOGIST) |
| CDSS-воркстация (C11-движки) | `/cdss/evaluate-encounter` | АРМ врача |
| Аудит-лог (append-only) | `audit_log` таблица | пишется на login/confirm; просмотр — psql (BY DESIGN из-под API нельзя) |
| Rate-limit + stagger | auth middleware (фича Миши) | серверный, невидим |

## Подключено к пациенту (PWA)

| Функция | Эндпоинт | Интерфейс |
|---|---|---|
| Привязка по QR (одноразовый токен, ИДС) | `/auth/bind` | экран «Привязка» |
| Ежедневный чек-ин (идемпотентный, офлайн-очередь) | `/patient/checkin` | 3 тапа + опросники + дневник |
| Опросники GAD-7/PHQ-9/C-SSRS-каскад | client-side scoring → checkin | пошагово, Duolingo-механика |
| Фидбек + тренд-инсайты + неделя терапии | локальные данные + ответ API | экран после отправки |
| Дневник состояния (сон/силы/симптомы/заметка) | в checkin payload | вкладка Сегодня |
| Прогресс: график GAD-7, настроение | localStorage + API | вкладка Прогресс |
| Ожидания/побочки/успокоение | статический контент из ОХЛП/РКИ | вкладка Терапия |

## Серверные функции без UI (осознанно)

| Функция | Эндпоинт | Почему без UI |
|---|---|---|
| Голосовые биомаркеры (DAM — англ. речь) | `/patient/voice-biomarkers` | П1: исследовательский режим, честно исключён из решений; UI подключим после RU-модели |
| followup-checkin (дневник врача между визитами) | `/patient/followup-checkin` | используется rule engine; UI врача — АРМ, план после субботы |
| Полный отчёт по 100 ЭМК для жюри | `/telemetry/full-benchmark-report` | демонстрируется на защите (curl/презентация), не для врача |
| Timeline/напоминания push | WebSocket | push-канал врачу живёт в открытой панели; пациентские push — после публикации в сторах |

## Итог
Все клинически значимые функции ядра и бэкенда подключены к интерфейсам.
Осознанно без UI: экспериментальный голосовой контур (П1), отчёт для жюри, psql-просмотр аудита.
