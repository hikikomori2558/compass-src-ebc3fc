# frontend_mis_mock — МИС-стенд «АИС Поликлиника» (демо)

Имитационный стенд типовой российской поликлинической ЭМК для демо субботы 25.10
(см. `docs/PLAN_SATURDAY.md`). Жанр: утилитарная рабочая лошадка — вкладки, плотные
таблицы, Tahoma, серо-синяя палитра, жёлтые/зелёные статусы приёма. Ноль градиентов.

**Честное позиционирование для жюри/трекера:** это собственный демо-стенд в жанре
типовой МИС (ЕМИАС/qMS-паттерны по общедоступным материалам), а не копия чужого ПО.
В реальном внедрении виджет COMPASS встраивается так же поверх МИС УЗ через
iframe/extension, обмен — FHIR R4 / СЭМД. Все пациенты синтетические (152-ФЗ).

## Состав

| Файл | Что делает |
|---|---|
| `index.html` | 5 экранов: вход, журнал приёма, карта ф. 025/у (5 вкладок, вкл. импорт истории), направления 057/у-04, красная шапка алертов |
| `app.js` | Логика МИС: вход (живой `/auth/login`), журнал с фильтрами, карта, WS-алерты, 057/у-04 |
| `compass_sidebar.js` | COMPASS-сайдбар 420px: живой `analyze-and-route` — светофор, подтверждения врача, PK RK45 168ч (canvas), XAI SHAP (ГОСТ Р 59921), CBR-когорты РКИ, паспорт провенанса, SLA |
| `styles.css` | Жанр МИС + контрастный Carbon-сайдбар |
| `data/patients_today.json` | Журнал на сегодня: 5 персон вебинара + 24 holdout + 9 из корпуса. Регенерация: `python3 scripts/gen_mis_journal.py` |

Важно: клиентские парсинги лаборатории/шкал в `app.js` — **только для отображения**
в карте. Все клинические решения считает серверный safe-pipeline — фронт их не дублирует.

## Запуск

Статика раздаётся FastAPI (единый origin с API — без CORS):

```bash
docker compose up -d          # PostgreSQL 16 + Redis
python3 -m backend.main       # или демо-скрипт scripts/demo_local.sh
# точка входа: http://127.0.0.1:8000/  -> редирект на /static/mis/index.html
```

Демо-доступ (seed): `neuro.ivlanov` / `compass-demo-2026` (невролог).
Локальная разработка фронта без бэкенда: `?api=http://127.0.0.1:8000` в URL.

## Замкнутый демо-цикл (главный вау-эффект)

1. Врач в МИС: журнал → пациент (09:20 «на приёме», Вебинар-1) → «Передать в COMPASS».
2. Сайдбар: AMBER → кнопки «Подтверждаю» (нет эпилепсии/ИМАО/…) → повторный разбор.
3. Врач: `POST /api/v1/auth/invite` → QR → телефон пациента привязывается (PWA, порт 5501).
4. Телефон: чек-ин C-SSRS = 4 → через ~12 мс в МИС вспыхивает красный баннер (WS).
5. Врач: «Подтвердить реакцию…» → аудит; при необходимости ф. 057/у-04 из сайдбара.

Контракт алерта: в WebSocket летит **пустой пинг** (alert_id без клиники) — клинику
врач достаёт авторизованным REST-запросом (152-ФЗ, решение 0-bis №2).
