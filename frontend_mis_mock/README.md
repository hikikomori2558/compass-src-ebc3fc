# frontend_mis_mock — МИС-стенд «АИС Поликлиника» (демо)

Имитационный стенд типовой российской поликлинической ЭМК для демо субботы 25.10
(см. `docs/PLAN_SATURDAY.md`).

**Дизайн — Ghost Admin напрямую (TryGhost/Ghost, MIT):** файлы в `vendor/ghost/`
скопированы байт-в-байт из репо (`apps/shade/*`, шрифты Inter Admin из
`apps/admin/src/assets/fonts`); CSS собирается ИХ же пайплайном — Tailwind v4 CLI
из их исходников (`ghost-shade.css` → `vendor/ghost/shade.compiled.css`,
пересборка: `scripts/build_ghost_css.sh`). Каркас повторяет `admin-frame.tsx`
(чёрная рамка, топ-бар 44px, безель 10px, страница-карточка r=10px) и
`floating-app-sidebar.tsx` (стекло 300px: `--surface-glass` + blur + их
glass-тень); кнопки/поля — их cva-рецепты (`button-variants.ts`,
`input-surface.ts`). COMPASS — слой поверх ЭМК в том же стеклянном жанре.
Атрибуция на защите: «дизайн — Ghost Admin (MIT), использован напрямую».

**Архитектура стенда = архитектура продукта:** интерфейс ЭМК живёт своей жизнью,
COMPASS — отдельный слой ПОВЕРХ него (панель настроек редактора Ghost как паттерн:
фиксирована справа, выезжает с их easing 450ms, скрим поверх ЭМК, кнопка-фаб возврата).
В реальном внедрении тот же сайдбар встраивается поверх МИС УЗ через iframe/extension,
обмен — FHIR R4 / СЭМД. Все пациенты синтетические (152-ФЗ).

в карте. Все клинические решения считает серверный safe-pipeline — фронт их не дублирует.

## Запуск

Статика раздаётся FastAPI (единый origin с API — без CORS):

```bash
docker compose up -d          # PostgreSQL 16 + Redis
python3 -m backend.main       # или демо-скрипт scripts/demo_local.sh
# точка входа: http://127.0.0.1:8000/  -> редирект на /static/mis/index.html
```

Демо-доступ (seed): `neuro.ivlanov` / `compass-demo-2026` (невролог).
Локальная разработка фронта без бэкенда: `?api=http://127.0.0.1:8000` в URL.

## Замкнутый демо-цикл (главный вау-эффект)

1. Врач в МИС: журнал → пациент (09:20 «на приёме», Вебинар-1) → «Передать в COMPASS».
2. Сайдбар: AMBER → кнопки «Подтверждаю» (нет эпилепсии/ИМАО/…) → повторный разбор.
3. Врач: `POST /api/v1/auth/invite` → QR → телефон пациента привязывается (PWA, порт 5501).
4. Телефон: чек-ин C-SSRS = 4 → через ~12 мс в МИС вспыхивает красный баннер (WS).
5. Врач: «Подтвердить реакцию…» → аудит; при необходимости ф. 057/у-04 из сайдбара.

Контракт алерта: в WebSocket летит **пустой пинг** (alert_id без клиники) — клинику
врач достаёт авторизованным REST-запросом (152-ФЗ, решение 0-bis №2).
