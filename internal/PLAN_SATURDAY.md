# ПЛАН НА СУББОТУ: тыкаемый продукт для созвона с трекером

Дата: четверг 23.10 → суббота 25.10. Цель субботы: трекер (и мы) тыкает в живой
продукт: врач в «привычной ЭМК» + наш COMPASS поверх + пациент с телефона.
Не презентация — продукт. Красота интерфейса — ПОСЛЕ закрытия плана разработки.

## 1. Ключевое архитектурное решение: МИС-стенд (имитатор ЭМК)

**Что просили:** продукт работает совместно с ЭМК гос. больниц РФ. Реальные АРМ
врача (ЕМИАС, qMS, МедИАлог, 1С:Медицина) — проприетарные, в открытом доступе
их нет, «спарсить и захостить» буквально = копирование чужого ПО.

**Что делаем (и что честно говорим трекеру/жюри):** собственный
**ДЕМО-СТЕНД МИС** в жанре типовой российской поликлинической ЭМК —
утилитарный интерфейс (вкладки, таблицы, кириллица, шапка «ГБУЗ ГП №… ДЗМ»),
собранный по ОБЩЕДУСТУПНЫМ материалам. Наш COMPASS работает поверх него
сайдбаром 420px — ровно та архитектура интеграции, что в реальном внедрении
(референс Eleos Health из презентации Панченко). На защите: «это имитационный
стенд типовой МИС; в проде наш виджет встраивается так же поверх реальной МИС
через iframe/extension, обмен — FHIR R4 / СЭМД».

**Референсы реализма (открытые, легальные):**
- ЕМИАС.ИНФО — пациентский портал (публичный, emias.info + RuStore скриншоты);
- обучающие видео «ЕМИАС рабочее место врача» на YouTube + скриншоты qMS/МедИАлог
  в СМИ/пресс-релизах — жанровые паттерны: верхнее меню-вкладки, жёлтые/зелёные
  статусы приёма, таблица пациентов на приёме, «журнал приёма», шаблон осмотра;
- обязательные реквизиты реального документооборота: ф. 025/у (осмотр),
  направление ф. 057/у-04, пометка «Записан из ЕМИАС», СЭМД-выгрузка.

**Дизайн-жанр (НЕ «нейроночный»):** утилитарная рабочая лошадка — System-шрифты,
плотные таблицы, спокойная палитра (серо-синий + зелёный/жёлтый/красный статусы),
ноль градиентов/стекла/тёмных тем. Выглядит скучно и правильно — как то, чем
врачи пользуются 8 часов в день. Контраст: наш сайдбар — чистый Carbon
(IBM/OpenMRS O3), читается как «современное поверх привычного».

## 2. Состав демо-стенда (архитектура v3: физическое разделение, «реальные условия»)

**Ключевое разделение (требование команды, 23.10):** ЭМК и COMPASS — РАЗНЫЕ
системы на уровне процессов и файлов:
- **ЭМК вендора** — `backend_emc/server.py` (порт 8100, свой API `/api/emc/*`,
  своя БД `backend_emc/data/`) + `frontend_emc/` (утилитарная гос-ЭМК: Tahoma,
  плотные таблицы, серо-синий жанр; ноль кода COMPASS). Публично: `/emc/`.
- **COMPASS** — `frontend_compass/`: `install.html` (хаб: JWT-вход врача +
  букмарклет-агент), `agent.js` (инжект в ЭМК, читает ВИДИМЫЕ данные карты
  с экрана, подсвечивает считанное, открывает iframe-сайдбар), `sidebar.*`
  (панель врача на своём origin: светофор, подтверждения, ОХЛП-находки, PK,
  XAI, CBR, паспорт, 057/у-04, QR-привязка, WS-алерты). Публично: `/`.
- Цепочка демо: хаб → закладка «COMPASS ▸» → карта в ЭМК → закладка →
  агент считал экран → панель поверх ЭМК с разбором. ЭМК не модифицируется.

**PWA пациента** (`/static/pwa/`): QR из сайдбара → чек-ин → алерт врачу.

(Историческая секция про 5 экранов МИС-стенда заменена разделённой архитектурой,
`frontend_mis_mock` удалён.)

**МИС-стенд `frontend_mis_mock/`** (статика, без сборки):
1. Вход врача (логин нейролог Иванов А.В. — уже в seed);
2. Журнал приёма: таблица ~24 пациентов на сегодня (статусы: ожидает/на приёме/закончен);
3. Карта пациента (осмотр ф. 025/у: жалобы, анамнез, лабы, назначения, шкалы) —
   сюда подгружается текст истории из нашего корпуса;
4. Экран «импорт истории» (вставка текста в 5 шаблонах — метрика №2 вживую);
5. Шапка-статус: «Алерты (N)» — красный бейдж неподтверждённых.

**COMPASS-сайдбар** (адаптация существующего frontend_doctor): светофор
ОБЯЗАТЕЛЬНО/ЖЕЛАТЕЛЬНО/In-Label, data_required + doctor_confirmations (кнопки
«подтверждаю»), PK-график с переключателем CYP2D6, коридор 36 нед., SLA-панель,
XAI/CBR-панель. Все вызовы — к живому API (Bearer-логин уже есть).

**PWA пациента** (frontend_patient, поднимает demo_local.sh): QR-привязка →
чек-ин → серия/скоринг (PRODUCT_DESIGN). Телефон трекера = пациент.

**Замкнутый демо-цикл (главный вау-эффект):** врач в МИС генерит QR →
телефон привязывается → телефон отправляет чек-ин с C-SSRS=4 → через ~12 мс
в МИС-стенде вспыхивает красный алерт → врач открывает, подтверждает,
формируется 057/у-04. Полный контур условия 5/6 на глазах у трекера.

**Данные:** 24 пациента holdout + выборка из корпуса 100 (все синтетические,
обезличенные — pii_scrubber в pipeline). Подгрузка в МИС-стенд из
`benchmarks/holdout/cases.json` + `synthetic_100_ehr_vignettes.json`.
